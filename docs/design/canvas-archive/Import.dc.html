What Runout keeps

When each play ended, how long it played, the track, artist, album and link, the device type, how it started and ended, shuffle, skip, offline and private-session flags.

What it drops

Your IP address, device identifier and username are never stored. The original files are not copied.
If the folder is wrong This folder doesn’t look like a Spotify export. Choose the unzipped folder from Spotify’s email, or the .zip itself.
Importing again later Plays already imported are skipped, so a newer export only adds what’s new.
